# StudyMate – Student Study Management System

StudyMate is a responsive Student Study Management System developed using HTML, CSS, and JavaScript. It helps students organize their subjects, manage study materials, track topics, and monitor their study progress.

## Features

- Add and manage subjects
- Add and track study topics
- Upload study materials
- Categorize materials into Textbooks, Solutions, Notes, PDFs, etc.
- Open uploaded study files
- Track topic completion
- Display overall study progress
- Search subjects and study materials
- Responsive design for mobile and desktop devices
- Uses browser local storage to save data

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- GitHub Pages
